# Soprano Price API

HTTP price crawler and public API for Soprano (gold, silver, coins).

- Live refresh every 10s: Tablo Tala (gold 18k, ounce, coins)
- Full HTTP refresh every 30 minutes (gold, silver global, coins)
- No Telegram bot, no Puppeteer/Chromium

Public endpoints are served via `bot.namakian.ir` in production.
